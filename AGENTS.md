# Diretrizes do FunkyEssentials

O FunkyEssentials é um plugin destinado à comunidade Minecraft e pode ser utilizado em qualquer servidor. O prefixo Funky identifica o plugin, mas não deve associá-lo a um servidor específico.

- Use linguagem independente de servidor em documentação, release notes, descrições, mensagens e materiais de divulgação.
- Não apresente o plugin como exclusivo ou oficial de um servidor específico.
- Preserve o nome FunkyEssentials e o prefixo Funky.
- Mantenha comandos, permissões e requisitos documentados no README e nas release notes.
